# CopyCat

A browser extension (Chrome, Brave, Edge) that helps **authors** post their **own** novel chapters to an author website: copy from a reader page or paste your own text, then publish, save as draft, or schedule.

> **For your own work only.** Use it only for novels you wrote or have permission to publish. Respect each website's rules.

Built-in websites: Royal Road, MegaNovel, GoodNovel, NovelCat. Other sites can be set up with the Pick buttons and "Extra buttons to click".

## Install
1. Download this repository (green **Code** button → **Download ZIP**) and unzip it somewhere permanent.
2. Open `chrome://extensions` (Brave: `brave://extensions`, Edge: `edge://extensions`).
3. Turn on **Developer mode**.
4. Press **Load unpacked** and choose the **`extension`** folder.
5. Click the extension icon to open the control window.

## Quick use
1. Open the reader page and your site's **Add chapter** page in two normal windows.
2. Choose them as Source and Target, press **Test reading** and **Test target**.
3. Pick the chapters, what to do with them (publish / draft / schedule), tick the rights box, press **Start**.
4. Try **one chapter as a draft** first on a new website.

Private/incognito and Tor windows: Chrome and Brave do not let extensions work in Tor windows. Use a normal window (optionally through a Tor proxy).
